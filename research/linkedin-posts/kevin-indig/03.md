## Post

A prompt tracker that runs each prompt once is measuring volatility, not visibility. I looked at 815,000 prompt-page pairs with AirOps. After the same prompt ran 3x in ChatGPT, only 2.2% of citations remained. Accuracy improves when you treat each prompt like a sample: run it 3-5 times, report confidence intervals, and keep the raw answers for audit. The goal is to measure variance instead of avoiding it.
